# COMSOL 円柱ピンフィン・ヒートシンク：CFD向けパラメータ／制約条件仕様

> **コメント記載方針**：以下の `# ...` はMarkdown上の説明コメントです。COMSOLの **Global Definitions > Parameters** に入力する場合は、`#` より左を **Expression**、コメント内容を **Description** 欄へ入力してください。

## 1. 対象スタディ

正方形ベース上に円柱ピンフィンを正方格子状に配置し、流れ方向を **+X** とする3D強制対流CFDスタディを想定する。

初期ベンチマークでは以下を基本設計変数とする。

```text
d_fin  # 円柱ピンフィン直径。主要設計変数。
h_fin  # 円柱ピンフィン高さ。主要設計変数。
PR_fin  # 無次元ピッチ比 p_fin/d_fin。小さいほどフィン密度が高い主要設計変数。
```

フィン本数 `Nx`, `Ny` は派生量として自動決定する。

---

## 2. 既存形状パラメータ

```text
L_base = 100[mm]  # ヒートシンクベースのX方向長さ。+Xを主流方向とする。
W_base = 100[mm]  # ヒートシンクベースのY方向幅。
t_base = 5[mm]  # ヒートシンクベース板厚。フィン根元Z座標の基準にもなる。

c_edge = 2[mm]  # ベース外周から最外周フィン外周まで確保する最小クリアランス。

d_fin  = 5[mm]  # 円柱ピンフィン直径。主要設計変数。
h_fin  = 25[mm]  # 円柱ピンフィン高さ。主要設計変数。
PR_fin = 2  # 無次元ピッチ比 p_fin/d_fin。小さいほどフィン密度が高い主要設計変数。

r_fin = d_fin/2  # フィン半径。d_fin/2 から算出する派生量。
p_fin = PR_fin*d_fin  # 隣接フィン中心間ピッチ。PR_fin*d_fin で算出する。
g_fin = p_fin-d_fin  # 隣接フィン表面間の最小ギャップ。p_fin-d_fin。

Nx = 1+floor((L_base-2*(c_edge+r_fin))/p_fin)  # X方向に配置されるフィン本数。floor() により離散的に変化する。
Ny = 1+floor((W_base-2*(c_edge+r_fin))/p_fin)  # Y方向に配置されるフィン本数。floor() により離散的に変化する。
N_fin = Nx*Ny  # ヒートシンク上の総フィン本数 Nx*Ny。

x_fin0 = -(Nx-1)*p_fin/2  # 配列をX方向中央配置するための基準フィン中心X座標。
y_fin0 = -(Ny-1)*p_fin/2  # 配列をY方向中央配置するための基準フィン中心Y座標。
z_fin0 = t_base  # 基準フィン根元のZ座標。ベース上面 t_base に一致させる。

c_edge_x_act = (L_base-(Nx-1)*p_fin-d_fin)/2  # 実際に確保されるX方向端部クリアランス。
c_edge_y_act = (W_base-(Ny-1)*p_fin-d_fin)/2  # 実際に確保されるY方向端部クリアランス。
```

## 3. CFD計算領域パラメータ

### 3.1 ダクト型ベンチマーク

初期ベンチマークでは、ヒートシンクをダクト底面にフラッシュマウントした構成とする。

```text
W_flow = W_base  # CFDダクトのY方向流路幅。初期ベンチマークでは W_base と一致。
H_flow = 50[mm]  # ベース上面からダクト上壁までの流体高さ。
```

`H_flow` は **ベース上面から上壁までの流体高さ** とする。

### 3.2 流路代表長さ

```text
A_ch  = W_flow*H_flow  # フィン無し基準ダクトの公称断面積 W_flow*H_flow。
P_ch  = 2*(W_flow+H_flow)  # 基準ダクト断面の濡れ縁長さ。水力直径計算に使用。
Dh_ch = 4*A_ch/P_ch  # 基準ダクトの水力直径 4A/P。Reynolds数や前後バッファ長の代表長さ。
```

### 3.3 上流・下流バッファ

ベンチマーク初期値：

```text
k_pre  = 3  # 入口からヒートシンクまでの上流バッファ長を Dh_ch の何倍にするかを表す係数。
k_post = 5  # ヒートシンクから出口までの下流バッファ長を Dh_ch の何倍にするかを表す係数。

L_pre  = k_pre*Dh_ch  # ヒートシンク上流側のCFDバッファ長。
L_post = k_post*Dh_ch  # ヒートシンク下流側のCFDバッファ長。

L_domain = L_pre+L_base+L_post  # 入口から出口までのCFD計算領域全長。
```

これは普遍的な必須値ではなく、入口条件・出口条件の影響をヒートシンク部から離すための初期設定である。

### 3.4 CFD領域座標

```text
x_dom_min = -L_base/2-L_pre  # CFD計算領域入口側のX座標。
x_dom_max =  L_base/2+L_post  # CFD計算領域出口側のX座標。

y_dom_min = -W_flow/2  # CFD計算領域のY方向最小座標。
y_dom_max =  W_flow/2  # CFD計算領域のY方向最大座標。

z_dom_min = t_base  # 流体領域のZ方向下端。ベース上面に一致。
z_dom_max = t_base+H_flow  # 流体領域のZ方向上端。ダクト上壁位置。
```

## 4. CFD向け幾何制約

### 4.1 フィン間オーバーラップ防止

単純成立条件：

```text
g_fin > 0  # 隣接フィン表面間の最小ギャップ。p_fin-d_fin。
```

CFDでは数値安定性・メッシュ解像度・過大圧損防止のため、さらに最小流路幅を設ける。

```text
g_cfd_min = 1.5[mm]  # CFD・メッシュ・圧力損失の観点から許容する最小フィン間ギャップ。

margin_gap = g_fin-g_cfd_min  # 最小ギャップ制約の余裕量。0以上で成立。
```

制約：

```text
margin_gap >= 0  # 最小ギャップ制約の余裕量。0以上で成立。
```

すなわち

```text
g_fin >= g_cfd_min  # 隣接フィン表面間の最小ギャップ。p_fin-d_fin。
```

または

```text
PR_fin >= 1 + g_cfd_min/d_fin  # 無次元ピッチ比 p_fin/d_fin。小さいほどフィン密度が高い主要設計変数。
```

---

### 4.2 ベース外へのフィンはみ出し防止

```text
margin_edge_x = c_edge_x_act-c_edge  # X方向外周クリアランス制約の余裕量。0以上で成立。
margin_edge_y = c_edge_y_act-c_edge  # Y方向外周クリアランス制約の余裕量。0以上で成立。
```

制約：

```text
margin_edge_x >= 0  # X方向外周クリアランス制約の余裕量。0以上で成立。
margin_edge_y >= 0  # Y方向外周クリアランス制約の余裕量。0以上で成立。
```

加えて、少なくともフィン1本がベース内に成立することを明示する。

```text
margin_fit_x = L_base-2*c_edge-d_fin  # X方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
margin_fit_y = W_base-2*c_edge-d_fin  # Y方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
```

制約：

```text
margin_fit_x >= 0  # X方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
margin_fit_y >= 0  # Y方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
```

---

### 4.3 上壁との干渉防止

```text
c_top_act = H_flow-h_fin  # フィン先端からダクト上壁までの実クリアランス。
c_top_min = 5[mm]  # CFDメッシュおよび流路確保のため要求する最小トップクリアランス。

margin_top = c_top_act-c_top_min  # トップクリアランス制約の余裕量。0以上で成立。
```

制約：

```text
margin_top >= 0  # トップクリアランス制約の余裕量。0以上で成立。
```

すなわち

```text
h_fin <= H_flow-c_top_min  # 円柱ピンフィン高さ。主要設計変数。
```

`c_top_min` は物理的な上壁クリアランスであると同時に、上壁とフィン先端間に十分なCFDメッシュを確保するための制約として扱う。

---

## 5. 最小流通面積／ブロッケージ制約

正方格子・流れ +X の場合、フィン中心を通る1列断面が代表的な最小流通断面となる。

### 5.1 ダクト断面積

```text
A_flow_nom = W_flow*H_flow  # フィン無し状態の公称流通断面積。
```

### 5.2 フィン列による代表遮蔽面積

```text
A_block_row = Ny*d_fin*h_fin  # 流れに直交する代表フィン1列が遮蔽する投影面積。
```

### 5.3 代表最小開口面積

```text
A_open_row = A_flow_nom-A_block_row  # 代表フィン列位置における近似開口面積。
open_row   = A_open_row/A_flow_nom  # 代表フィン列位置の開口率 A_open_row/A_flow_nom。
BR_row     = A_block_row/A_flow_nom  # 代表フィン列位置のブロッケージ率 A_block_row/A_flow_nom。open_row と補数関係。
```

ここで

```text
open_row + BR_row = 1  # 開口率とブロッケージ率は補数関係で、両者の和は1。
```

### 5.4 CFDベンチマーク用ガード

```text
open_row_min = 0.35  # 極端な閉塞形状を除外するための最小許容開口率。ベンチマーク用ガード値。

margin_open = open_row-open_row_min  # 開口率制約の余裕量。0以上で成立。
```

制約：

```text
margin_open >= 0  # 開口率制約の余裕量。0以上で成立。
```

`open_row_min=0.35` は数値的・圧損的に極端な閉塞形状を除外するための **ベンチマーク用初期ガード値** であり、製品設計の普遍的な推奨値ではない。

## 6. 流量・局所速度の診断パラメータ

流量を設計条件として与える場合：

```text
Qv = 100[L/min]  # 入口で与える体積流量。

U_in = Qv/A_flow_nom  # フィン無し公称ダクト断面積基準の入口平均流速。
```

最小開口部での一次近似速度：

```text
U_gap_est = U_in/open_row  # 代表最小開口部での近似平均速度。過大加速ケース検出用の診断量。
```

この値は厳密な局所最大速度ではないが、設計スイープ前に過大加速ケースを検出するための診断量として有用。

---

## 7. Reynolds数診断

流体物性を

```text
rho_f  # 流体密度。Reynolds数計算に使用。
mu_f  # 流体の動粘度ではなく粘性係数（動的粘度）。Reynolds数計算に使用。
```

とした場合、ダクト基準 Reynolds 数：

```text
Re_ch = rho_f*U_in*Dh_ch/mu_f  # 水力直径 Dh_ch と入口平均流速 U_in に基づくダクトReynolds数。
```

フィン間ギャップ基準の近似 Reynolds 数：

```text
Re_gap = rho_f*U_gap_est*g_fin/mu_f  # フィン間ギャップ g_fin と近似局所速度 U_gap_est に基づく診断Reynolds数。
```

`Re_ch`, `Re_gap` は Laminar Flow / Turbulent Flow の選択と、結果整理のための診断量として使用する。ピンフィン配列では遷移条件が形状依存のため、単一の Reynolds 数閾値を幾何制約として固定しない。

---

## 8. 非圧縮性近似を使う場合の速度ガード

気体を非圧縮性流体として扱う場合、必要に応じて Mach 数診断を追加する。

```text
c_sound  # 流体中の音速。気体のMach数診断に使用。
Ma_gap = U_gap_est/c_sound  # 代表最小開口部の近似Mach数 U_gap_est/c_sound。
```

初期ガード例：

```text
Ma_max = 0.3  # 非圧縮性近似を適用する場合の許容最大Mach数。
margin_Ma = Ma_max-Ma_gap  # Mach数制約の余裕量。0以上で成立。
```

制約：

```text
margin_Ma >= 0  # Mach数制約の余裕量。0以上で成立。
```

液体CFDでは通常、この制約は不要。

## 9. CFDメッシュへ連動させる派生パラメータ

幾何を振ったときに、最小ギャップだけメッシュ不足になることを防ぐため、メッシュサイズも幾何から自動計算する。

### 9.1 フィン間ギャップ

```text
N_gap = 8  # フィン間最小ギャップ幅に配置したい目標要素数。
hmax_gap = g_fin/N_gap  # ギャップ解像度から決まる局所最大要素サイズ。
```

### 9.2 フィン直径周り

```text
N_diam = 12  # フィン直径1個分を円周・周辺流れ解像の基準として分割する目標要素数。
hmax_diam = d_fin/N_diam  # フィン直径解像度から決まる局所最大要素サイズ。
```

### 9.3 フィン先端と上壁間

```text
N_top = 6  # フィン先端と上壁間クリアランスに配置したい目標要素数。
hmax_top = c_top_act/N_top  # トップクリアランス解像度から決まる局所最大要素サイズ。
```

### 9.4 局所CFD最大要素サイズ

```text
hmax_cfd_local = min(hmax_gap,hmax_diam,hmax_top)  # ギャップ・フィン直径・トップクリアランスのうち最も厳しい条件から決める局所最大要素サイズ。
```

この値をフィン周囲・ギャップ・先端領域の Size ノードの Maximum element size に利用する。

> 境界層メッシュは別途設定する。乱流モデルで壁面解像型を使う場合は、最終的に `y+` に基づいて第1層厚さを決定する。

## 10. CFD用制約余裕パラメータ一覧

最適化・DOEでは、制約を直接記述するより **margin >= 0** 形式へ統一すると扱いやすい。

```text
margin_gap    = g_fin-g_cfd_min  # 最小ギャップ制約の余裕量。0以上で成立。
margin_edge_x = c_edge_x_act-c_edge  # X方向外周クリアランス制約の余裕量。0以上で成立。
margin_edge_y = c_edge_y_act-c_edge  # Y方向外周クリアランス制約の余裕量。0以上で成立。
margin_fit_x  = L_base-2*c_edge-d_fin  # X方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
margin_fit_y  = W_base-2*c_edge-d_fin  # Y方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
margin_top    = H_flow-h_fin-c_top_min  # トップクリアランス制約の余裕量。0以上で成立。
margin_open   = open_row-open_row_min  # 開口率制約の余裕量。0以上で成立。
```

気体・非圧縮性CFDの場合のみ：

```text
margin_Ma = Ma_max-Ma_gap  # Mach数制約の余裕量。0以上で成立。
```

成立条件：

```text
margin_gap    >= 0  # 最小ギャップ制約の余裕量。0以上で成立。
margin_edge_x >= 0  # X方向外周クリアランス制約の余裕量。0以上で成立。
margin_edge_y >= 0  # Y方向外周クリアランス制約の余裕量。0以上で成立。
margin_fit_x  >= 0  # X方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
margin_fit_y  >= 0  # Y方向に少なくともフィン1本を収容できる寸法余裕。0以上で成立。
margin_top    >= 0  # トップクリアランス制約の余裕量。0以上で成立。
margin_open   >= 0  # 開口率制約の余裕量。0以上で成立。
```

必要時：

```text
margin_Ma >= 0  # Mach数制約の余裕量。0以上で成立。
```

## 12. CFDベンチマークとしての推奨制約セット

初期スタディでは次を基本セットとする。

```text
# Geometry validity
g_fin >= g_cfd_min  # 隣接フィン表面間の最小ギャップ。p_fin-d_fin。
c_edge_x_act >= c_edge  # 実際に確保されるX方向端部クリアランス。
c_edge_y_act >= c_edge  # 実際に確保されるY方向端部クリアランス。
d_fin <= L_base-2*c_edge  # 円柱ピンフィン直径。主要設計変数。
d_fin <= W_base-2*c_edge  # 円柱ピンフィン直径。主要設計変数。
h_fin <= H_flow-c_top_min  # 円柱ピンフィン高さ。主要設計変数。

# CFD flow-area validity
open_row >= open_row_min  # 代表フィン列位置の開口率 A_open_row/A_flow_nom。
A_open_row > 0  # 代表フィン列位置における近似開口面積。

# Integer geometry validity
Nx >= 1  # X方向に配置されるフィン本数。floor() により離散的に変化する。
Ny >= 1  # Y方向に配置されるフィン本数。floor() により離散的に変化する。
```

気体・非圧縮性モデルの場合のみ：

```text
Ma_gap <= Ma_max  # 代表最小開口部の近似Mach数 U_gap_est/c_sound。
```

## 13. 最適化における重要注意点

`Nx`, `Ny` は `floor()` を含むため、`d_fin` または `PR_fin` の変化に伴ってフィン本数が離散的に変化する。

したがって：

- **Parametric Sweep / DOE**：そのまま使用可能。
- **勾配ベース最適化**：`Nx`, `Ny` を固定したサブ問題に分割する。
- **フィン本数も最適化**：`Nx`, `Ny` を離散設計変数として扱うか、固定本数ケースを複数比較する。

CFDではフィン本数の変化により流路トポロジー、圧力損失、局所Reynolds数、メッシュ構造が同時に変わるため、初期段階では DOE / Parametric Sweep を推奨する。

## 14. 初期ベンチマークの主要設計変数

```text
d_fin  # 円柱ピンフィン直径。主要設計変数。
h_fin  # 円柱ピンフィン高さ。主要設計変数。
PR_fin  # 無次元ピッチ比 p_fin/d_fin。小さいほどフィン密度が高い主要設計変数。
```

CFD性能評価値としては、少なくとも以下を取得する。

```text
T_max  # 解析領域または指定固体領域の最大温度。熱設計制約・目的関数候補。
T_base_avg  # ヒートシンクベースの面積または体積平均温度。熱性能比較指標。
Q_heat  # ヒートシンクから流体へ移動した除熱量／熱流量。
Delta_p  # 入口と出口、または指定断面間の静圧差として定義する圧力損失。
R_th  # 熱抵抗。例：(T_base_avg-T_in)/Q_heat。小さいほど熱性能が高い。
PumpPower  # 送風・ポンプ動力相当。代表的には Delta_p*Qv（効率を考慮する場合は別途除算）。
```

これにより、例えば

- `R_th` 最小化
- `Delta_p` 上限制約
- `PumpPower` 上限制約
- `T_max` 上限制約

といった熱性能と流動損失のトレードオフ最適化へそのまま展開できる。
