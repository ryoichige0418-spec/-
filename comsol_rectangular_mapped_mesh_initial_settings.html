COMSOL 一様矩形断面流路
Mapped＋Sweptメッシュ初期設定手順

層流域の共通メッシュを、断面全体のMappedメッシュと流路方向のSweptメッシュで構成するための実務用初期設定ガイド。外部ライブラリを使用せず、iPhone・オフライン表示に対応。

この資料の使い方

1. 推奨初期設定の要約 2. 変数の定義 3. COMSOLメッシュシーケンス 4. 断面Mappedメッシュの設定 5. 流路方向Sweptメッシュの設定 6. 初期設定計算ツール 7. 作成後の確認とAudit

1. 推奨初期設定の要約

基本構成：入口または出口の矩形断面をMapped四角形メッシュで作成し、その断面メッシュを流路長さ方向へSweptして六面体メッシュを生成します。対向壁からBoundary Layersを別途挿入しません。
設定対象標準初期値設定意図
メッシュシーケンスUser-controlled mesh分割数と集中率を明示的に管理する
狭い断面方向24要素、Exponential、Element ratio 6、Symmetric ON両壁面を細かく、中央を緩やかに粗くする
広い断面方向12要素以上、Exponential、Element ratio 3、Symmetric ON側壁の速度勾配も解像しつつ過剰分割を避ける
流路方向要素長 ≈ 0.5 Dh一様な流路・境界条件に対する量産用開始値
Mapped面入口面をSource face入口断面の分割をそのまま下流へSweepする
Swept要素HexahedraMapped四角形断面から六面体体積要素を作る
Auditメッシュ断面1.2～1.3倍、軸方向1.25倍主要評価量の離散化誤差を確認する
初期値であって最終値ではありません。共通メッシュとして固定する前に、総除熱量、圧力損失、出口温度、最大固体温度をAuditメッシュと比較してください。

2. 変数の定義

記号意味単位初期設定での用途
W矩形断面の幅。通常は長い側m または mm幅方向分割数 NW の計算
H矩形断面の高さ。通常は狭い側m または mm壁面集中を強く設定する基準方向
L流路長さm または mmSwept方向分割数 NL の計算
Dh水力直径m または mm流路方向の初期要素長を決める
NH高さ方向の総要素数—標準初期値24。偶数を使用
NW幅方向の総要素数—中央部の要素縦横比から決定
NL流路方向の要素層数—SweptのDistributionに入力
RH高さ方向のElement ratio—中央要素厚さ／壁面要素厚さ。標準6
RW幅方向のElement ratio—中央要素幅／側壁要素幅。標準3
qH高さ方向で隣接要素寸法が増える倍率—滑らかさの確認。標準1.15～1.20
hw,H高さ方向の壁面隣接要素厚さm または mm壁面温度・熱流束勾配の解像指標
hc,H高さ方向の中央要素厚さm または mm幅方向・軸方向要素寸法の基準
Acs断面中央部の許容要素縦横比—初期値1.5。上限目安2
αL流路方向要素長／水力直径—標準0.5。小さいほど軸方向が細かい
Dh = 2WH / (W + H)

矩形断面では、流路断面積を WH、濡れ縁長さを 2(W＋H) とした水力直径です。

3. COMSOLメッシュシーケンス

Model Builder上では、次の順序にします。

Component 1 → Mesh 1 → Mapped 1 → Distribution-H / Distribution-W → Swept 1 → Distribution-L
1
Mesh 1のSequence typeをUser-controlled meshへ変更
Physics-controlled meshのままでは、分割数を量産条件間で厳密に固定しにくいためです。
2
Mapped 1で入口または出口の矩形面を選択
Source faceとして使用する面です。入口面を推奨します。
3
Mapped 1の下に高さ方向・幅方向のDistributionを追加
各Distributionでは、互いに向かい合う2本のエッジを同時に選択します。
4
Swept 1で流体ドメインを選択
Mapped済み面をSource face、反対側をDestination faceとして流路方向へ展開します。
5
Swept 1の下にDistribution-Lを追加
流路方向の要素層数を直接指定します。
重要：Mappedメッシュでは論理的に向かい合う辺の要素数が一致している必要があります。高さ方向の2辺は同じ NH、幅方向の2辺は同じ NW にします。

4. 断面Mappedメッシュの初期設定

4.1 Mapped 1本体

COMSOL項目初期設定説明
Geometric entity levelBoundary3DモデルのSource faceを対象にする
Boundary Selection入口矩形面出口でも可能だが、流れ方向と対応しやすい入口を推奨
Edge GroupsまずAutomatic単純矩形なら通常は自動認識でよい。向かい合う辺が誤って組み合わされた場合のみ手動設定
Sizeサブノード原則不要四辺をDistributionで制御するため。SizeはMappedではMaximum element sizeのみ参照され、同じ辺ではDistributionが優先される

4.2 高さ方向 Distribution-H

流路の狭い方向であり、通常は速度・温度勾配の解像を最優先します。

COMSOL項目標準初期値調整範囲
Edge Selection高さ方向の対向2辺同じ設定を2辺へ同時適用
Distribution typePredefined—
Number of elements2420～32、薄い熱境界層では32～40
Growth rateExponential通常はLinearより滑らか
Element ratio6弱い集中3～5、強い集中8～12
Symmetric distributionON両壁面へ同じ密度で集中
Reverse directionOFF対称分布では通常不要
mH = NH/2
qH = RH1/(mH−1)
hw,H = (H/2) × (qH−1) / (qHmH−1)
hc,H = RH × hw,H

qHは隣接要素間の増加倍率です。初期設定では 1.15～1.20を狙い、1.25を超える場合は、Element ratioを下げるか要素数を増やします。

4.3 幅方向 Distribution-W

側壁もno-slip壁であるため、初期状態では完全な等間隔よりも、弱い対称集中を推奨します。

条件Number of elementsElement ratio推奨
全4壁の熱流束・壁温が重要中央要素縦横比から算定4～6高さ方向に近い壁面集中
主に上下壁が熱交換面12以上、中央要素縦横比から算定2～3標準設定
W/Hが大きく側壁影響が小さい12以上1～2Auditで圧損・熱流量を確認して採用

幅方向分割数は、断面中央の要素幅 hc,W が、次式を満たす最小の偶数にします。

hc,W / hc,H ≤ Acs

標準初期値は Acs＝1.5、許容上限の目安は2です。下記計算ツールが NW を自動算定します。

4.4 Mapped面の目視確認

  • 両壁面の第一要素厚さが左右・上下で対称になっている
  • 中央付近に極端に薄い要素や急激な寸法変化がない
  • 向かい合う辺の要素数が一致している
  • Element ratioを上げすぎず、隣接増加率が滑らかである

5.2 Distribution-L

COMSOL項目標準初期値説明
Geometric entity levelDomainSwept方向の分布はドメインに設定
Distribution typeFixed number of elements量産解析で同じ軸方向層数を再現
Number of elementsNL＝ceil[L/(0.5Dh)]一様形状・一様境界条件の開始値
EquidistantON一様流路ではまず等間隔を使用
Δstarget = αL × Dh
NL = ceil(L / Δstarget)

標準初期値は αL＝0.5です。入口近傍、熱源端部、境界条件の切替位置で軸方向勾配が大きい場合は、流路をPartitionし、その区間だけ αL＝0.1～0.25へ下げます。

長い流路で全長を過剰に細かくしない：入口発達部だけを細分化したい場合、1本の強い指数Distributionで全長をつなぐより、入口から5～10Dh程度でドメインを分割して、区間ごとに固定要素長を設定する方が再現性と管理性に優れます。

7. 作成後の確認とAudit

7.1 メッシュ生成直後

  • 全流体領域が六面体要素で構成されている
  • 入口面と出口面の断面トポロジーが一致している
  • 壁面から中央まで要素寸法が滑らかに増加している
  • 隣接増加率 q が概ね1.25以下である
  • 流路中央の断面要素縦横比が2以下を目安に収まっている
  • メッシュ生成時にWarningまたはInformationノードが追加されていない

7.2 ProductionとAuditの初期差

方向ProductionAudit初期設定
高さ方向NH次の偶数へ丸めた 1.3NH
幅方向NW次の偶数へ丸めた 1.2NW
流路方向NL切り上げた 1.25NL
Element ratioRH, RW原則同じ値を維持

7.3 共通メッシュ固定の合格目安

評価量Production－Audit差の初期目安
総除熱量1%以下
圧力損失1～2%以下
出口温度0.2 K以下
最大固体温度0.2～0.5 K以下
温度均一性指標2%以下
不合格時の修正方向：除熱量・壁温が未収束なら断面壁面側を優先して細分化します。圧力損失が未収束なら断面分割に加えて入口部・流路方向も確認します。最大固体温度だけが未収束なら、流体メッシュではなく固体側の熱源近傍・流体界面近傍メッシュが原因の場合があります。

8. COMSOL入力用の初期値テンプレート

Mapped 1 / Distribution-H：Predefined, Number = 24, Exponential, Element ratio = 6, Symmetric = ON
Mapped 1 / Distribution-W：Predefined, Number = 計算値 NW, Exponential, Element ratio = 3, Symmetric = ON
Swept 1 / Distribution-L：Fixed number of elements, Number = ceil(L/(0.5*Dh)), Equidistant = ON
Parameters：Dh = 2*W*H/(W+H)

モデルパラメータとして、例えば W_ch、H_ch、L_ch、Dh、nH_mesh、nW_mesh、nL_meshを登録すると、メッシュ設定の管理とバージョン比較が容易になります。
